A framework-neutral application layer for modern WordPress front ends, with a first-class Vue adapter.

== Description ==

Vaust is an experimental developer toolkit for building a WordPress front end once and delivering it as an installable theme or a headless application.

== Installation ==

1. Upload the `vaust` directory to `/wp-content/plugins/`.
2. Activate Vaust through the Plugins screen in WordPress.
